# Discord Bot Project (Updated)

هذا المشروع يحتوي على التحديثات الكاملة لضمان استقرار البوت وحفظ البيانات دائمياً.

## المميزات المحدثة:
1. **قاعدة بيانات SQLite ثابتة:** حفظ الإعدادات وقيود البان وسجلات المشرفين بشكل دائم وعدم مسحها عند إعادة تشغيل البوت.
2. **حماية التداخل والنصوص الطويلة:** معالجة تلقائية لأي نصوص تزيد عن 1024 حرف للوقاية من أخطاء Discord API (`50035`).
3. **تجاهل أخطاء الصلاحيات:** عدم إغراق الشات بالرسائل عند محاولة استخدام أمر بدون صلاحيات.
4. **التحقق الهرمي للرتب:** حماية البوت والأعضاء الأعلى رتبة من الأوامر التعسفية.

## طريقة التشغيل:
1. قم بإنشاء ملف `.env` ووضع توكن البوت فيه:
   `DISCORD_TOKEN=your_token`
2. ثبّت المتطلبات:
   `pip install -r requirements.txt`
3. شغل البوت:
   `python bot/main.py`
